⏱️ 等时圈通勤工具

高德密钥设置
申请：console.amap.com → 应用管理 → 创建 Key（服务平台选「Web端(JS API)」）。密钥保存在浏览器本地，不会上传服务器。

① 起点位置（可设两个，方便双人/双地点对比）

← 先选槽位再搜索/点图

② 添加等时圈（可叠加多个）

③ 候选地点

导入自己的候选清单（每行一个地点名，可带城市，逗号分隔）
导入后自动判断是否在各等时圈内，再点「批量算通勤」。
说明：步行/骑行圈为直线距离近似（步行≈2.8km/h、骑行≈9km/h）；地铁/公交圈来自高德到达圈（不含等车与换乘耗时），以「真实通勤时间」为最终依据。候选地点来自高德 POI 或手动导入。配色：≤30分钟 绿，≤45 黄，≤60 橙，>60 红。

欢迎使用等时圈通勤工具

本工具使用高德地图服务，需要你在本地配置高德 JS API Key 与安全密钥。密钥仅保存在浏览器 localStorage 中，不会上传到任何服务器。

如果你还没有密钥，可前往 console.amap.com 免费申请：应用管理 → 创建 Key → 服务平台选「Web端(JS API)」。

也可以把密钥填入仓库的 config.yaml 后重新部署（公开仓库请谨慎，配置文件仍会被浏览器访问）。
